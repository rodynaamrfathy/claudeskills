A growing collection of Claude skills, tools, and resources that make working with AI more intentional, productive, and creative.

Some are my own experiments, others are open-source projects and resources worth keeping close.

## Skills

### Anti-AI Slop

A skill for building better web interfaces with Claude.

We've all seen the same predictable AI-generated interfaces: generic layouts, repetitive cards, unnecessary gradients, and typography without much thought.

This skill encourages more deliberate design decisions:

- **Visual design:** Typography, color, spacing, proportions, and layout.
- **Interaction:** Meaningful animations, transitions, and hover states.
- **Content:** Realistic content instead of generic placeholders.
- **Quality:** Accessibility, semantic HTML, and maintainable code.
- **Design review:** Catching common AI-generated design patterns.

## Philosophy

I believe AI tools become much more useful when we give them the right context, constraints, and workflows.

The goal isn't to make AI do everything. It's to make the collaboration between humans and AI better.

This collection will keep evolving as I discover useful tools, build new skills, and experiment with different workflows.
