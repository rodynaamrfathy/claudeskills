# Claude Skills

A growing collection of Claude skills, experiments, and workflows that make working with AI a little more intentional.

This is where I keep skills I've built, collected, or found useful while experimenting with AI-assisted development and creative workflows.

The goal is simple: make Claude better at the things we actually care about, beyond just getting things done.

## Skills

### 🎨 Anti-AI Slop

A skill for building better web interfaces with Claude.

We've all seen them: the same predictable layouts, generic typography, unnecessary gradients, repetitive card designs, and interfaces that look like they were generated by AI without much thought.

I built this skill to push against those patterns.

Instead of simply telling Claude what not to do, it encourages deliberate design decisions around:

- **Visual design:** Color, typography, spacing, proportions, and layout.
- **Interaction:** Meaningful animations, transitions, and hover states.
- **Content:** Realistic content instead of generic placeholders and repetitive copy.
- **Quality:** Accessibility, semantic HTML, and maintainable code.
- **Design review:** A final checklist to catch common AI-generated design patterns.

[View anti-ai-slop.skill](./anti-ai-slop.skill)
